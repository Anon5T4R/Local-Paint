Local Raster portable mode

While this file sits next to localraster.exe, Local Raster keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the LocalRasterData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Local Raster with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\LocalRaster for settings
and %LOCALAPPDATA%\LocalRaster\Recovery for crash-recovery autosaves. If LocalRasterData can't be
written (for example on a read-only drive), Local Raster says so and uses those folders instead.
