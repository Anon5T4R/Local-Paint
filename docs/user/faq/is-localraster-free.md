Yes. Local Raster is free and open-source creative software. The code is licensed under MIT or Apache 2.0, your choice, and is on [GitHub](https://github.com/Styx-Studios/Local-Raster).

Local Raster works offline. Its smart selection tools run on your computer, with no cloud and no account.

See [Install Local Raster](../getting-started/install.md) to download it.
